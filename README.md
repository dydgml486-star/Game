# 들판 수비대 (Field Defense)

브라우저에서 바로 실행되는 타워 디펜스 게임. 설치·빌드 없이 `index.html`을 열면 된다.

## 플레이
- 타워 선택 후 풀밭 칸 클릭/터치 → 설치. 설치된 타워 클릭 → 강화(최대 Lv.3)·판매(투자액 70%).
- 궁수탑 50G(단일·빠름) / 대포탑 90G(범위) / 얼음탑 70G(감속)
- 5웨이브마다 보스(성문 도달 시 생명 -5). 생명 20 소진 시 종료.
- 단축키: 1·2·3 타워, Space 웨이브 시작, P 일시정지, F 배속(1/2/3), Esc 선택 해제

## 파일
- `index.html` : 단독 실행용 (game.html을 HTML 문서로 감싼 것)
- `game.html` : 본문 소스 (Artifact 게시용)

# 빙글도끼 숲 (Axe Forest)

도는 도끼·곡괭이와 활·총으로 숲·곰 숲·채석장·공룡 계곡을 채집·사냥하고, 판매·컨베이어·일꾼으로 자동화한 뒤 최종 보스 뿌잉뿌잉을 쓰러뜨리는 게임. Three.js r128(cdnjs + jsdelivr GLTFLoader·SkeletonUtils).

- 그래픽(1단계): 캐릭터(주인공·손님·일꾼·계산원)는 KayKit 모델 + 걷기·달리기·작업·쓰러짐 애니메이션, 나무·바위·풀꽃·기지 소품은 Kenney 모델. 회전 도끼·곡괭이·활도 모델로 교체(등급 색·에인션트 발광 유지). 판매대·발판·컨베이어는 복셀 유지
- 그래픽(2단계): 곰·티라노·뿌잉뿌잉과 채집품(나무·고기·돌·보석·공룡 고기)을 로우폴리 3D로 새로 만듦. 부위별 도형을 정점색 한 메시로 구워 그려서 짐승 한 마리당 메시 3~5개. 곰 네 발 걷기, 티라노 두 발·턱, 보스 양팔 동작
- 렌더링: 원래 해상도(기기 배율 최대 1.5) + sRGB·ACES 톤매핑 + 부드러운 그림자. 2초 평균 40fps 미만이면 해상도를 단계적으로 낮춤
- 모델 파일을 못 받으면 해당 부분만 기존 복셀 모델로 대신 그림 (정적 서버가 아닌 file://로 열면 전부 복셀)

- 이동: 드래그(따라오는 가상 조이스틱)·WASD, 가속·감속 적용. 기본 속도 6.4(신발 강화 1단계당 +12%), 달리기 동작 속도도 이동 속도에 맞춤 / 시야: 휠·핀치·+/- / 장비창: I 키 또는 장비 버튼
- 구역: 숲(나무 2G) → 곰 숲(고기 8G, 250G) → 채석장(돌 3G·보석, 800G) → 공룡 계곡(공룡 고기 40G, 3,000G) → 최종 보스(10,000G)
- 가방: 나무·고기·광물 칸이 따로 있음. 보석은 가방이 아니라 보석함으로
- 컨베이어: 투입구 반경 3 안에 들어가면 가방 속 채집품이 벨트로 들어가 판매대로 자동 운반 (구역 전체 자동 흡수는 제거)
- 일꾼·사냥꾼·광부: 최대 14개 운반, 작업 속도·생산량 2배
- 무기점: 사냥 활(500G)·사냥 총(1,500G). 강화 Lv3/6/9에 스킬 해금(활: 멀티샷·독·관통 / 총: 화염·폭발·속사)
- 뽑기: 보석 5개(10회 50개). 레어 82% / 유니크 10% / 레전드 5% / 에인션트 3%. 활·총·도끼, 스킬 1/2/3/6개, 피해 ×1.5/2.3/3.6/9. 에인션트는 메테오·신성 오라 포함, 무지개 발광·오브 이펙트
- 뽑기 천장: 레전드 이상 없이 50회째면 레전드 이상 확정(레전드:에인션트 = 5:3), 뽑기 화면에 남은 횟수 표시
- 무기 합성(장비 탭): 레어·유니크 3개, 레전드 5개 → 윗등급 1개(레어→유니크→레전드→에인션트), 장착 중·무기점 무기 제외, 한번에 합성 지원
- 오프라인 수익: 접속하지 않은 동안(최대 6시간) 일꾼 1.2G/s·사냥꾼 3G/s·광부 1.5G/s × 간판 보너스(계산원 없으면 절반)의 30%, 보석은 광부 1명당 1시간에 1개(최대 12개)
- 보석 드롭: 수정 바위 1개(30% 확률로 +1), 일반 바위 5%, 티라노 25%. 광부는 광석만 2배로 챙기고 보석은 그대로
- 의상실: 외형 10종(기본~살라스 100,000G). 살라스는 금빛 머리, 타오르는 기운, 번개 이펙트
- 최종 보스 뿌잉뿌잉: HP 60,000, 근접 16·충격파 24 피해, 35% 이하 분노. 첫 처치 50,000G + 보석 30 + 진화석 1
- 보스 별 단계: 잡을 때마다 ★1→★11까지 강해짐(단계마다 체력 +60%, 공격력 +20%). 재처치 보상 15,000G×(1+0.5×단계) + 보석 10 + 진화석 1(★6 이상 2)
- 몬(동료 몬스터): 몬 부화장 발판에서 부화·레벨업(최대 Lv30). 윤우몬(벌목, 1,000G) / 준우몬(회복·자석, 곰 숲 개방 후 3,000G) / 채아몬(채굴, 채석장 개방 후 8,000G) / 연준몬(전투, 공룡 계곡 개방 후 20,000G). Lv10 진화는 금화 3배, Lv20 진화는 금화 3배 + 진화석 3개
- 몬 추가: 말몬(이동 속도·가방, 곰 숲 개방 후 5,000G) / 동욱몬(얼음 파동으로 둔화·피해, 채석장 개방 후 12,000G) / 호선몬(받는 피해 감소, 보스 첫 처치 후 40,000G) / 전설 용구몬(불덩이 범위 공격, 습격 5웨이브 방어 후 300,000G + 진화석 5). 몬 8마리는 두 줄로 따라다님
- 습격 모드: 모든 강화 발판이 MAX가 되면 열림. 2분 30초 준비(지금 시작 버튼으로 앞당김) → 옆마을 부족(고블린·오크, 5웨이브마다 부족장)이 남쪽 길과 서쪽 숲에서 판매대로 쳐들어옴. 웨이브마다 체력 +18%·공격력 +8%(복리). 모두 처치하면 3,000G×웨이브 + 보석 + (5웨이브마다) 진화석, 판매대 방어도 100이 다 깎이면 금괴 30%·재고 절반을 잃고 같은 웨이브 재도전
- 이펙트: GPU 포인트 발광 파티클(가산 합성) — 타격 불꽃, 도끼 궤적, 폭발 섬광·연기, 번개, 메테오 꼬리, 구매 반짝임, 발걸음 먼지
- 저장: 자동 저장(4초, 이 기기) + 계정 저장(30초) + 저장/불러오기 버튼(수동 슬롯) + 백업 코드
- 이전 저장 호환: 대검은 사용 금액 환불, 발판으로 산 활은 무기점 사냥 활로 이전
- 주소 끝에 `#debug`를 붙이면 테스트용 `window.__dbg` 노출

## 3D 에셋 (axe-forest/assets)

모두 CC0(퍼블릭 도메인, 상업 이용 가능, 출처 표기 의무 없음). 원본 라이선스 파일을 같은 폴더에 둠.

- KayKit – Adventurers Character Pack 2.0 (Kay Lousberg, www.kaylousberg.com): `chars/`, `anims/`, `items/`
- Kenney – Nature Kit 2.1 (www.kenney.nl): `nature/`
- Kenney – Survival Kit 2.0 (www.kenney.nl): `survival/`

웹 배포용으로 모든 모델을 텍스처·버퍼 내장형 glTF(.json)로 변환해 둠 (아티팩트가 .glb를 서빙하지 않음). 미리보기: `axe-forest/sample-assets.html`. 본 게임과 샘플 모두 정적 서버(GitHub Pages 등)에서 열어야 모델이 로드됨.

아티팩트로 게시할 때는 게임이 읽는 모델 67개(약 6MB)를 `assets/...` 경로 그대로 보조 파일로 함께 올린다.
