# 들판 수비대 (Field Defense)

브라우저에서 바로 실행되는 타워 디펜스 게임. 설치·빌드 없이 `index.html`을 열면 된다.

## 플레이
- 타워 선택 후 풀밭 칸 클릭/터치 → 설치. 설치된 타워 클릭 → 강화(최대 Lv.3)·판매(투자액 70%).
- 궁수탑 50G(단일·빠름) / 대포탑 90G(범위) / 얼음탑 70G(감속)
- 5웨이브마다 보스(성문 도달 시 생명 -5). 생명 20 소진 시 종료.
- 단축키: 1·2·3 타워, Space 웨이브 시작, P 일시정지, F 배속(1/2/3), Esc 선택 해제

## 파일
- `index.html` : 단독 실행용 (game.html을 HTML 문서로 감싼 것)
- `game.html` : 본문 소스 (Artifact 게시용)

# 빙글도끼 숲 (Axe Forest)

도는 도끼·곡괭이와 활·총으로 숲·곰 숲·채석장·공룡 계곡을 채집·사냥하고, 판매·컨베이어·일꾼으로 자동화한 뒤 최종 보스 뿌잉뿌잉을 쓰러뜨리는 게임. Three.js r128(cdnjs), 박스 병합 메시 + 저해상도 렌더링으로 도트 3D 느낌.

- 이동: 드래그(따라오는 가상 조이스틱)·WASD, 가속·감속 적용 / 시야: 휠·핀치·+/- / 장비창: I 키 또는 장비 버튼
- 구역: 숲(나무 2G) → 곰 숲(고기 8G, 250G) → 채석장(돌 3G·보석, 800G) → 공룡 계곡(공룡 고기 40G, 3,000G) → 최종 보스(10,000G)
- 가방: 나무·고기·광물 칸이 따로 있음. 보석은 가방이 아니라 보석함으로
- 컨베이어: 설치한 구역에서 줍는 채집품은 가방을 거치지 않고 판매대로 자동 운반, 가방 속 물건도 자동 투입
- 일꾼·사냥꾼·광부: 최대 14개 운반, 작업 속도·생산량 2배
- 무기점: 사냥 활(500G)·사냥 총(1,500G). 강화 Lv3/6/9에 스킬 해금(활: 멀티샷·독·관통 / 총: 화염·폭발·속사)
- 뽑기: 보석 5개(10회 50개). 레어 82% / 유니크 10% / 레전드 5% / 에인션트 3%. 활·총·도끼, 스킬 1/2/3/6개, 피해 ×1.5/2.3/3.6/9. 에인션트는 메테오·신성 오라 포함, 무지개 발광·오브 이펙트
- 뽑기 천장: 레전드 이상 없이 50회째면 레전드 이상 확정(레전드:에인션트 = 5:3), 뽑기 화면에 남은 횟수 표시
- 무기 합성(장비 탭): 레어·유니크 3개, 레전드 5개 → 윗등급 1개(레어→유니크→레전드→에인션트), 장착 중·무기점 무기 제외, 한번에 합성 지원
- 오프라인 수익: 접속하지 않은 동안(최대 8시간) 일꾼 1.2G/s·사냥꾼 3G/s·광부 1.5G/s × 간판 보너스(계산원 없으면 절반), 광부 1명당 5분에 보석 1개
- 의상실: 외형 10종(기본~살라스 100,000G). 살라스는 금빛 머리, 타오르는 기운, 번개 이펙트
- 최종 보스 뿌잉뿌잉: HP 60,000, 근접 16·충격파 24 피해, 35% 이하 분노. 첫 처치 50,000G + 보석 30
- 저장: 자동 저장(4초, 이 기기) + 계정 저장(30초) + 저장/불러오기 버튼(수동 슬롯) + 백업 코드
- 이전 저장 호환: 대검은 사용 금액 환불, 발판으로 산 활은 무기점 사냥 활로 이전
- 주소 끝에 `#debug`를 붙이면 테스트용 `window.__dbg` 노출
