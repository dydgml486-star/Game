# 들판 수비대 (Field Defense)

브라우저에서 바로 실행되는 타워 디펜스 게임. 설치·빌드 없이 `index.html`을 열면 된다.

## 플레이
- 타워 선택 후 풀밭 칸 클릭/터치 → 설치. 설치된 타워 클릭 → 강화(최대 Lv.3)·판매(투자액 70%).
- 궁수탑 50G(단일·빠름) / 대포탑 90G(범위) / 얼음탑 70G(감속)
- 5웨이브마다 보스(성문 도달 시 생명 -5). 생명 20 소진 시 종료.
- 단축키: 1·2·3 타워, Space 웨이브 시작, P 일시정지, F 배속(1/2/3), Esc 선택 해제

## 파일
- `index.html` : 단독 실행용 (game.html을 HTML 문서로 감싼 것)
- `game.html` : 본문 소스 (Artifact 게시용)

# 모사사우루스 바다 모험 (`mosasaurus/`)

5살 아이 눈높이의 바닷속 횡스크롤 게임. `mosasaurus/index.html`을 열면 바로 실행된다.

## 플레이
- 화면을 손가락(마우스)으로 누른 채 움직이면 모사사우루스가 따라간다. 키보드는 방향키/WASD.
- 물고기 +1점, 반짝이는 금붕어 +5점, 작은 상어 +3점(닿기만 하면 콱). 해파리에 닿으면 잠깐 어지러울 뿐 하트는 줄지 않는다.
- 일정 거리를 가면 메갈로돈 등장 → 빨간 줄(돌진 경로)이 보이면 위/아래로 피한다 → 돌진 후 어지러워할 때(별이 돔) 닿으면 콱! 한 번 문다.
- 하트 3개. 메갈로돈 돌진에 맞을 때만 줄고, 떠다니는 하트 방울로 회복. 다 잃어도 보스전부터 바로 다시 시작(길 처음부터 반복하지 않음).
- 3단계: 얕은 바다(보스 체력 3, 돌진 1회) → 산호초 바다(4, 2회) → 깊은 바다(5, 3회).
- 앙! 버튼(스페이스) = 앞으로 빠르게 돌진. P/Esc = 멈춤.

## 파일
- `mosasaurus/index.html` : 단독 실행용
- `mosasaurus/game.html` : 본문 소스 (Artifact 게시용)
