# 들판 수비대 (Field Defense)

브라우저에서 바로 실행되는 타워 디펜스 게임. 설치·빌드 없이 `index.html`을 열면 된다.

## 플레이
- 타워 선택 후 풀밭 칸 클릭/터치 → 설치. 설치된 타워 클릭 → 강화(최대 Lv.3)·판매(투자액 70%).
- 궁수탑 50G(단일·빠름) / 대포탑 90G(범위) / 얼음탑 70G(감속)
- 5웨이브마다 보스(성문 도달 시 생명 -5). 생명 20 소진 시 종료.
- 단축키: 1·2·3 타워, Space 웨이브 시작, P 일시정지, F 배속(1/2/3), Esc 선택 해제

## 파일
- `index.html` : 단독 실행용 (game.html을 HTML 문서로 감싼 것)
- `game.html` : 본문 소스 (Artifact 게시용)

# 빙글도끼 숲 (Axe Forest)

캐릭터 주변을 도는 도끼로 나무를 베고 곰을 사냥해 판매대에서 팔고, 번 돈으로 강화·자동화하는 게임. Three.js r128(cdnjs) 사용, 저해상도 렌더링으로 도트 3D 느낌.

- 이동: 화면 드래그(가상 조이스틱) 또는 WASD·방향키
- 흐름: 벌목 → 가방에 쌓임 → 노란 판매대 발판에 내려놓기 → 초록 계산대 발판에서 손님에게 판매
- 발판 위에 서 있으면 돈이 들어가며 구매: 도끼 추가·강화, 회전 강화, 가방, 신발, 간판(가격·손님 증가)
- 자동화: 계산원(자리를 비워도 판매), 일꾼(자동 벌목·납품, 최대 5명)
- 곰 숲(200G 개방): 곰 고기 8G, 곰에게 맞으면 HP 감소, 기절하면 가방이 비워짐
- 진행은 브라우저 localStorage에 저장. 주소 끝에 `#debug`를 붙이면 테스트용 `window.__dbg` 노출
