# 들판 수비대 (Field Defense)

브라우저에서 바로 실행되는 타워 디펜스 게임. 설치·빌드 없이 `index.html`을 열면 된다.

## 플레이
- 타워 선택 후 풀밭 칸 클릭/터치 → 설치. 설치된 타워 클릭 → 강화(최대 Lv.3)·판매(투자액 70%).
- 궁수탑 50G(단일·빠름) / 대포탑 90G(범위) / 얼음탑 70G(감속)
- 5웨이브마다 보스(성문 도달 시 생명 -5). 생명 20 소진 시 종료.
- 단축키: 1·2·3 타워, Space 웨이브 시작, P 일시정지, F 배속(1/2/3), Esc 선택 해제

## 파일
- `index.html` : 단독 실행용 (game.html을 HTML 문서로 감싼 것)
- `game.html` : 본문 소스 (Artifact 게시용)

# 빙글도끼 숲 (Axe Forest)

캐릭터 주변을 도는 도끼·곡괭이로 나무·곰·바위를 채집해 판매대에서 팔고, 번 돈으로 강화·자동화하는 게임. Three.js r128(cdnjs), 박스 병합 메시 + 저해상도 렌더링으로 도트 3D 느낌.

- 이동: 화면 드래그(가상 조이스틱) 또는 WASD·방향키 / 시야: 휠, 두 손가락 핀치, +/- 버튼
- 구역: 기본 숲(나무 2G) → 곰 숲(고기 8G, 250G 개방) → 채석장(돌 3G·보석 15G, 800G 개방, 곡괭이 추가) → 공룡 계곡(공룡 고기 40G, 3,000G 개방)
- 구매: 강화 발판에 올라가면 구매 창이 뜨고, 구매 버튼(또는 E·Enter·Space)을 눌러야 결제됨. 밟기만 해서는 돈이 나가지 않음
- 판매: 판매대 발판에 내려놓기 → 손님이 계산대에서 구매 → 금괴 더미로 쌓임 → 밟으면 수거
- 자동화: 계산원·계산대 추가, 일꾼·사냥꾼·광부, 구역별 컨베이어(투입구 → 판매대), 벨트 속도, 자석, 자동 입금
- 강화 합계(힘)에 따라 아바타 6단계 외형 변화, 도끼·곡괭이도 공격력 단계별 색 변화
- 체력(HP): 곰 1, 티라노 4 피해. 0이 되면 기절 → 가방 속 채집품을 그 자리에 떨어뜨리고 기지에서 부활(2초 무적). 4초간 안 맞으면 회복. 최대 체력 = 10 + 갑옷 강화×5 + 아바타 단계×3
- 무기: 도끼·곡괭이(회전), 활(가장 가까운 곰·공룡 자동 사격), 대검(주기적 360도 베기, 나무도 벰), 갑옷 강화
- 공룡 계곡(곰 숲 북쪽, 3,000G 개방): 티라노사우루스 6마리(HP 220, 추격·물기), 공룡 고기 40G, 정글 나무(나무 4개)
- 효과음: WebAudio 합성(외부 파일 없음), 소리 켬/끔 버튼
- 저장: 4초마다 이 기기(localStorage) 자동 저장 + claude.ai 계정 저장(db capability, 사용자별 비공개 문서 `data/users/<id>/save`, 30초 주기), 저장 버튼
- 계정 저장은 진행도(누적 판매액 + 강화 단계)가 더 큰 쪽을 채택 — 새 기기의 빈 게임이 기존 진행을 덮어쓰지 않음
- 백업 코드(AXF1.…): 백업 버튼에서 복사/붙여넣기로 기기·링크 간 진행 이동
- 주소 끝에 `#debug`를 붙이면 테스트용 `window.__dbg` 노출
